RAGFlow: удалено лишнее
из рабочего runtime

Лаба использует локальный минимизированный образ на базе прежнего v1.0.0-rc3. Приложение не пересобиралось и не обновлялось: хэш Go-бинарника совпадает.

Размер по Podman777,5 → 705,8 МБ
Уменьшение71,7 МБ · 9,22%
Установленные пакеты141 → 133

Слои объединены в один: удалённые Python/Vim-файлы не остаются в нижних слоях нового образа. Исходный образ сохранён отдельно для отката. Размеры — фактическое поле Size в Podman, не измерение compressed download.

Что изменилось

УдаленоСохранено
vim, vim-common, vim-runtimeGo backend и nginx
libpython3.12-minimal, libpython3.12-stdlib, libpython3.12t64Нативные парсеры, модели, tokenizer assets, шрифты
unzip, iproute2 (ip/ss)bash/dash для entrypoint; curl для healthcheck; Essential perl-base; apt/dpkg

Node/npm отсутствовали в исходном runtime и не появились. Vim со встроенным Python удалён. Общий autoremove не использовался, чтобы не удалить нативные зависимости вне Debian dependency metadata.

Это не shell-less/distroless образ. Shell, Essential Perl и другие системные средства остаются. Удаление пакетов уменьшает runtime, но не является границей защиты от произвольного выполнения кода и не исправляет F01/F02.

Что проверено

Сначала отдельный стек со своими семью контейнерами и volumes на временном loopback18081, затем рабочая лаба на18080:

  • Загрузка и нативный парсинг TXT, DOCX и PDF: каждый дал один chunk.
  • Реальный Elasticsearch full-text retrieval нашёл уникальный маркер во всех трёх форматах.
  • Скачанный оригинал DOCX совпал с загруженными байтами.
  • Вход администратора и обычного тестового пользователя, healthcheck.
  • Регистрация выключена; API MCP через nginx возвращает404.
  • 133 установленных пакета; Vim/Python/Node и libpython не обнаружены.
  • Go binary SHA256: 69a35469bf70ccd2a78733c86c51aba9e8fc510f3e51a367e5bf0a0512f62ece, тот же до и после.

После очистки исходные счётчики сохранились: 3 datasets, 1356 документов, 2 пользователя. Это проверка counts, а не полный побайтовый аудит хранилищ. Тестовые пользователи/документы удалены; временный стек, его сети и volumes удалены. Другие шесть рабочих сервисов не пересоздавались.

Векторный retrieval с реальной embedding-моделью не перепроверялся: существующий локальный model endpoint был выключен. Тест выполнял настоящий BM25/full-text путь без искусственных embeddings. Иные форматы документов и агентские функции отдельно не тестировались.

Текущий образ и откат

localhost/ragflow-lab-minimal@sha256:8803ecb0a91edef2a44b731cc7249adcde080a19b9ec60eedf98b700d7026459

UI: http://127.0.0.1:18080/. Осталась только прежняя loopback-публикация18080.

В папке лабы сохранены исходный Compose и приватный dump БД (права600): data/backups/runtime-minimal-2026-11-13/. Dump в этот отчёт не включён.

cp data/backups/runtime-minimal-2026-11-13/compose.yaml.original compose.yaml
./lab.sh compose up -d --no-deps --wait --wait-timeout 240 ragflow

Для возврата образа не требуется восстанавливать БД или удалять volumes. Подробности повторной сборки и диагностики добавлены в README лабы.
