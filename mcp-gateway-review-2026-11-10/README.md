# MCP Gateway: корпоративная безопасность и обзор рынка

Срез исследования: **10 ноября 2026 года**. Язык отчёта: русский.

Откройте `report.html` в обычном браузере. Для самого отчёта достаточно одного HTML: CSS, SVG и JavaScript встроены; сетевых запросов, внешних шрифтов, CDN и аналитики нет. Ссылки на CSV/JSON требуют сохранения соседней папки `data`.

## Содержимое

- `report.html` — оформленный отчёт: 16 решений, 4 именованных примера корпоративной практики, 45 первичных источников, архитектура, требования, модель рисков, рекомендации, экономика и программа пилота.
- `data/solutions.json` — карточки решений и статусы возможностей.
- `data/comparison.csv` — матрица сравнения; UTF-8 с BOM для удобного открытия.
- `data/sources.json` — реестр ссылок, типы источников, даты и подтверждаемые тезисы.
- `data/enterprise-cases.json` — кейсы Uber, Cloudflare, Bloomberg и Block с границами подтверждения.
- `data/requirements.json` — требования и критерии приёмки.
- `data/poc-checklist.json`, `data/poc-checklist.csv` — 12 проверок пилота; в CSV оставлены поля для результата и evidence.
- `data/research-log.json` — ссылки, собственные краткие пересказы и решения по отбору материалов. Полные статьи и длинные дословные выдержки не входят в комплект.
- `validation.json` — результаты технических проверок и ограничения QA.
- `manifest.json` — SHA-256 файлов комплекта.
- `template.html`, `build_report.py` — редактируемый шаблон и генератор без сторонних зависимостей.

## Как читать данные

Статусы `features` расположены в порядке: enterprise identity, tool-level policy, argument-level conditions, content inspection, MCP runtime isolation.

- `doc` — функция публично описана; это не результат испытания.
- `integration` — реализуется отдельным компонентом или интеграцией.
- `limited` — в рассмотренном сценарии есть существенное ограничение.
- `verify` — необходимо подтвердить; отметка не означает отсутствия функции.

Размещение: `managed`, `self` (self-host/private, иногда по запросу), `local`. Конкретные редакции, поддерживаемые версии и условия поставки нужно подтвердить при выборе.

## Ограничения и проверка

Документальное исследование, без развёртывания и сравнительного тестирования продуктов. Рекомендации, приоритеты, схема архитектуры и PoC — аналитический синтез. Самоописание компании или поставщика не считается независимым доказательством эффективности защиты.

Проверены структура HTML, уникальность ID, все внутренние ссылки, наличие файлов загрузки, JSON/CSV, синтаксис JavaScript и его обработчики на DOM fixture: поиск, фильтры, синхронизация матрицы, пустой результат, переход к карточке, тема и вызов печати. Визуальный browser QA и печатный layout не проверены: встроенный браузер не разрешает открытие локальных `file://` URLs. Макет содержит адаптивные стили и отдельные print styles.

## Пересборка

```sh
python3 build_report.py
```

Генератор перезаписывает отчёт и основные JSON/CSV. После правок для актуального архива потребуется обновить manifest и ZIP.
