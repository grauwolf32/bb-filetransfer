Обзор guardrails для LLM-инфраструктуры
Дата среза: 10 ноября 2026 года (Europe/Moscow).

Откройте report.html в браузере. Интернет для оформления и интерактивных элементов не нужен.
Печать / PDF открывает стандартный диалог браузера; таблица CSV доступна по кнопке.

Файлы:
report.html — автономный отчёт на русском языке.
data/sources.json — 35 источников, URL, дата проверки, краткие заметки и тип подтверждения.
data/solutions.json — подробные карточки 14 решений.
data/solutions.csv — те же данные в UTF-8 BOM с разделителем ; для табличных редакторов.
data/research.json — примеры компаний, требования и исходные допущения расчёта.
build_report.py — локальный генератор HTML и CSV (Python 3, стандартная библиотека).

Методика: открытые первичные источники. Полные копии страниц не архивировались.
Продуктовые возможности не проверялись hands-on. Это выборочный обзор, не рейтинг.
Для S07 доступен индексированный фрагмент: оговорка указана в отчёте и реестре.
Стоимость и статусы Preview/Beta проверяются повторно перед внедрением.
